# meld — trust model

- **Capability URL + TTL.** The URL grants access while the meld is live.
- **Host-readable while live.**
- **Anyone with the link can read it.**
- **Not for secrets/credentials/regulated.**
- **Dissolves on TTL.** Unresolved melds last up to one hour; resolved melds about ten minutes.
- **Mint-next.** Create another meld URL and put it in the reply.

meld is an ephemeral context handoff, not a vault. The host stores ordinary context only for the live TTL, then deletes the meld. There are no accounts or long-term content archives. Use meld for ordinary, disposable handoffs only.
